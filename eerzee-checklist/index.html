ROUTE PLAN

D0 + 两天一夜建议节奏

D-2 至 D0 · 海拔适应
尽量先在中等海拔住两晚，不直接冲进高海拔

如时间不允许，D0 至少留在山下休整，不要抵达后直接进山。正常吃饭、补水、早睡；和向导当面确认营地海拔、最高点、天气、信号、撤退路线、公共装备与车接驳。感冒、发热、腹泻或明显头痛则取消进山。

D1 · 建议 08:00 前后出发
起点 → 魔幻森林 → 墨海附近营地

第一小时刻意放慢，每 45–60 分钟补一次水和小食，短休 5–10 分钟。目标 15:00–16:00 前到营地；到达后立刻换掉潮湿贴身层、穿羽绒服、吃热食。

D2 · 先评估，再出发
墨海 → 红海 / 水晶区域 → 下撤

只有在孩子无明显头痛恶心、精神正常且能吃早餐时继续。只捡地表裸露的小块水晶，不敲岩层、不离开向导和主路线；无论是否找到，都给下撤留足时间。

PACE & CHILD

孩子的节奏

  • 孩子只背水、零食、抓绒或薄外套，目标 2–3 kg 内。
  • 用“走到下一棵树 / 下一个缓坡”拆小目标，不用终点施压。
  • 每次休息顺便问：头疼吗？恶心吗？冷不冷？还能吃东西吗？
  • 停止行走就马上加保暖层；不要等他说冷才穿。
  • 全程让孩子走在爸爸或向导视线内，不单独钻林找水晶。
速度标准：大人觉得“慢得有点烦”，通常才接近孩子在高海拔的合适节奏。
CAMP ROUTINE

到营地后的顺序

  1. 先穿保暖层，再搭帐篷；孩子不要站着等到冷。
  2. 铺好地布、充气垫与睡袋，检查潮湿和漏气。
  3. 换干袜和干燥贴身层，湿衣隔离收纳。
  4. 烧水、吃含碳水的热食，小口持续喝水。
  5. 头灯、鞋、雨衣、撤退包放在伸手可取的位置。
  6. 夜里复查孩子精神、呼吸与头痛情况。
FOOD PLAN

两天一夜食物模板

D1 早餐：山下吃饱，以碳水为主，不尝试陌生油腻食物。

D1 路餐：饭团 / 面包、牛肉干、能量棒、坚果、巧克力、小袋水果干，少量多次。

D1 晚餐：方便米饭或面 + 脱水蔬菜 + 汤；先保证能吃下，再谈“户外仪式感”。

D2 早餐：燕麦 / 面包 + 热饮；另留一份应急口粮，不纳入正常计划。

起步各带约 1–1.5 L 水，是否需要滤水器、营地水源是否可靠，必须由向导提前确认。
BEFORE YOU GO

出发前 48 小时

  • 看逐小时降雨、风速、体感温度；不只看“晴 / 雨”图标。
  • 把完整路线、向导电话、车牌和预计返回时间发给山下联系人。
  • 手机离线地图下载完成，所有设备充满电，电池放内层保温。
  • 帐篷在家完整搭一次；睡垫充气过夜查漏；炉头点火测试。
  • 新鞋至少穿走两次；修剪脚趾甲，准备热点贴 / 防磨贴。
  • 所有睡眠和保暖用品分别放防水内袋，不依赖背包防雨罩。
GO / NO-GO

每天早上的出发判断

状态表现行动
可以继续精神、食欲、步态正常；无头痛或仅轻微且不加重保持慢节奏，持续观察
停止上升头痛加重、恶心、明显乏力、无法进食、反应变慢告知向导，休息评估；不改善就下撤
立即下撤 / 求援步态不稳、意识异常、静息呼吸困难、嘴唇发紫、咳粉红泡沫痰下降海拔、保暖、吸氧并联系救援
核心原则：

不要让止痛药、吸氧或“再坚持半小时”成为继续上升的理由。高海拔不适最有效的处理是停止上升；严重或进行性症状必须下撤。

CABIN BAG

随身上飞机

  • 身份证件、现金、手机、相机与其他贵重物品
  • 充电宝和备用锂电池：必须随身，做好绝缘保护；境内航班还要检查清晰有效的 3C 标识及召回状态
  • 常用药、处方证明、一套关键保暖层
  • 到达后立刻要用且托运行李丢失会影响出发的物品

航空公司对充电宝容量、标识和件数可能有额外要求，出发前按实际承运航司最新规则核对。

CHECKED BAG

托运与禁限带

  • 登山杖、帐篷地钉、刀具和多功能工具建议托运。
  • 气罐不可带上客机，也不能托运；抵达后在当地购买。
  • 防晒喷雾、液体和药品按机场与航司规定打包。
  • 背包托运要收紧肩带腰带，最好套运输袋，避免传送带勾挂。
最稳妥方案：大背包与尖锐器材托运；父子各带一个小随身包，装证件、锂电池、药品和关键衣物。
GUIDE BRIEFING

向导必须回答的 10 个问题

  1. 准确起点、营地、最高点海拔各是多少？
  2. 两天每天里程、累计爬升与预计用时？
  3. 当前路况、积水、积雪与夜间最低温？
  4. 孩子不适时最近撤退点和下撤耗时？
  5. 哪里有稳定水源，是否必须过滤 / 煮沸？
  6. 向导带不带急救包、氧气、对讲机或卫星通信？
  7. 帐篷、炉头、气罐和炊具由谁提供、谁背？
  8. 是否有额外背夫或备用向导可分担装备？
  9. 进山许可、保险、接驳车和返程时间如何安排？
  10. 什么天气条件会取消、改线或提前下撤？
WEIGHT

负重怎么分

爸爸：帐篷 / 公共装备、两人的大部分睡眠系统、食物、急救与备用衣物。起步尽量控制 10–12 kg；若明显超过，优先让向导或背夫分担帐篷和食物。

孩子：约 1 L 水、小食、抓绒 / 薄外套、自己的头灯和哨子，2–3 kg 内。

向导：出发前明确公共帐篷、炉具、燃料、炊具、氧气和应急通信到底由谁提供及携带。

重量与预算为常见轻量装备的估算值，实际以你的现有装备、向导提供项目和承运航司规定为准。出发前根据天气与向导信息做最终删减。
